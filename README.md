# DM Staff.
DM Staff es una aplicacion de discord en desarrollo que ofrece herramientas para jugar Dungeons and Duels,
un juego de rol en desarrollo el cual une a Yu-Gi-Oh! y Dungeons and Dragons.

El equipo encargado de el desarrollo de DM Staff es Duels and Dungeos en Discord developer portal.
El servidor de discord hogar de DM Staff es [D.A Dueling Club](https://discord.gg/bRjZSpPrVM) en el cual se podra solicitar cierta información de el desarrollo y eventos.
